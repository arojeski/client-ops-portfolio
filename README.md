# Anastasia Rojeski — Career Site

A lightweight static career portfolio. No build tools are required.

## Privacy mode
This version is intentionally configured to discourage search-engine discovery:
- `noindex, nofollow, noarchive` meta directives
- `robots.txt` disallows crawling
- the email address is assembled only when a visitor clicks the Email button

Important: this is **not access control**. Anyone who knows or receives the public URL can still open and share it.

## Publish with GitHub Pages
1. Create a GitHub account if needed.
2. Create a public repository.
3. Upload all files from this folder to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/ (root)`, then Save.
